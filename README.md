# Shipping Label Generator 📦

**Breaking Limits Edition** — Generate professional shipping labels like the real ones.

Inspired by this sample label:

- **FROM:** REEVES MUSKY  
  1945 Cedar Avenue  
  Austin, Texas 78701

- **TO:** Anita Vincent  
  4817 Friendly St.  
  Pace, Florida 32571

- Shipper: SHIPPER GLOBAL EXPRESS
- Tracking: 11861-87236-402392053
- State: FL

## Features
- Generate printable shipping labels (HTML/PDF ready)
- Custom FROM / TO addresses
- Barcode simulation
- Shipper branding
- One-click copy for thermal printers

## Quick Start
Open `label-template.html` in your browser and edit the fields live.

Or run:
```bash
node generate-label.js
```
